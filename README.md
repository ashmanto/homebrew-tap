# Homebrew tap

Homebrew casks for [Sandtable](https://github.com/ashmanto/sandtable).

## Install Sandtable

```bash
brew install --cask ashmanto/tap/sandtable
```

The cask also installs `gh` and `tmux`. Sandtable needs Claude Code as well, which you can install with `brew install --cask claude-code`.
